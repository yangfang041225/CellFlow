# CellFlow 外部试用准入清单（Phase II）

> 说明：如果只用于个人学习，本清单可忽略；保留它是为了区分“自己学”和“给别人用”的证据要求。
> 个人使用请看 `docs/personal_learning_guide.md`。

日期：2026-10-26
状态：**受控试用可；无监督外部使用不可**
基线：PR #1 `4fcb61f` → 分支 `phase2/scientific-validation`

## A. 使用前必须确认

- [ ] 受试者知道当前是 **v0.4.0 候选、未发布**，不是正式版。
- [ ] 受试者只使用本机、单用户、`127.0.0.1` 模式。
- [ ] 受试者知道 **L2 只对同数据/同参数的参考对照成立**，不自动适用于自己的数据。
- [ ] 受试者知道 **veloVI 未验证收敛/种子稳健**，只能作为探索。
- [ ] 受试者知道 **CellRank 命运概率不是谱系追踪**，单终末状态无语义。
- [ ] 使用真实胰腺数据复跑通过（scVelo 三模式、CellRank 自动/固定终末）。
- [ ] 受试者数据有备份；程序不修改源文件，但会写 `results/`。

## B. 允许的操作

- 导入 h5ad / 10x / CSV（CSV 走预览确认）。
- 运行 QC / Leiden / DPT / PAGA / scVelo / CellRank / veloVI（短训练）。
- 查看 A/B 报告与证据等级，导出 PDF/ZIP。
- 对比两次运行（严格比较契约）。

## C. 禁止或必须标注

- ❌ 声称“全部科学验收通过”。
- ❌ 把 veloVI 结果当作收敛/稳健。
- ❌ 把命运概率/箭头当作已验证生物学结论。
- ❌ 在未提交干净机器安装记录前承诺普通用户可独立安装。
- ❌ 提交大型真实数据或凭据到 GitHub。

## D. 试用后必须收集

1. 数据来源、SHA-256、层类型（spliced/unspliced/Ms/Mu）。
2. 实际执行步骤与参数（config.json）。
3. 证据等级与报告位置。
4. 失败/取消/重启记录。
5. 内存与耗时（16 GB / 无 GPU 参考机）。

## E. 升级为“可独立使用”前必须补齐

- [x] 固定终末与自动终末使用**独立预处理**分别对照（2026-10-26 完成，概率差 0）。
- [ ] veloVI 至少一次足够 epoch 的收敛诊断 + validation ELBO。
- [ ] 干净 Windows 标准用户：安装、启动、导入、运行、导出、重启、卸载。
- [ ] 强制杀进程/磁盘写满后的孤儿与残留检查。
- [ ] 多屏 125/150/200% DPI。
- [ ] A/B 报告与证据等级的人工科学审阅。
