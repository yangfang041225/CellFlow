## 证据等级契约

L0–L4 是项目内部标签。普通任务最多自动到 L1；外部基准不回写历史任务。L2 加载器只支持 scVelo 速度矩阵，必须校验 `reference_comparison.manifest` 清单自身哈希、started_at、输入/配置/环境/源码摘要，以及参考和本任务 velocity.npz；按唯一 ID 对齐重新算误差。完整有限覆盖未达到就不升级整项。CellRank 外部对照单列，不能升级整个 auto/veloVI 任务。L3/L4 永不自动。

清单 schema=1、passed=true、method；binding 包含 input_sha256、code_sha256、started_at、config_sha256、environment_sha256；reference/candidate 各含 path 与 sha256。所有路径必须在本任务目录。该机制防止错用文件和声明升级，不是对恶意伪造本地证据的签名认证；参考过程独立性仍须审阅运行记录。

## 使用边界与尚未验证项

适合在明确方法假设和输入来源后个人学习、探索、复现固定协议。数值对照只覆盖770细胞胰腺子集、固定参数和现有软件版本；不能推广为全数据、其他组织、不同版本或生物学正确性。无 L3/L4 证据，不可据此对外给出谱系、因果、临床或准确率结论。

磁盘经验估计不保证足够空间；没有真实填盘/OOM。Windows 检验覆盖自建进程的父身份错配/死亡、supervisor死亡与Job Object清理、计算树失败与后续排队恢复；真实 Qt正常导入关闭另测。原生 Qt/启动器为同一进程，独立端口下强杀该进程、单独结束其 API 树及再次启动均已复验；首次探针因重定向器 PID 与实际 Qt PID 不同失败，修正探针后重跑，未据此修改算法。Qt 渲染子进程独立强杀、多屏 DPI、干净机器标准账户安装尚未验证；监督进程与计算任务按独立后台策略可继续，重新启动恢复队列。
