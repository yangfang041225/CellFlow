# CellFlow 操作手册（完整版）

> 这个工具是干什么的：把 **scRNA-seq 数据**导入一个本机网页，先检查数据质量、判断哪些方法在你当前数据上**合法可用**，
> 然后调用对应的计算模型，给出图形与指标，最后导出两份中文报告。
> 默认全部在本机 CPU 上跑；**安装完依赖、数据齐备后，分析、出图、写报告都可以断网完成**。

---

## 1. 这个工具能回答什么问题

| 你的问题 | 对应方法（用途分类） | 前提 |
|---|---|---|
| **我不想挑方法，能不能一个矩阵进去、一份报告出来？** | **一键分析（推荐，默认开启）** | **只要一个 `.h5ad`；有剪接层就自动加速度与命运** |
| 我的数据质量怎么样？哪些细胞明显异常？ | 数据质控与 PCA（质控与结构） | 只要能读出表达矩阵 |
| 这些细胞能不能分成几群？ | 自动分群 Leiden + UMAP（轨迹与分群） | 有表达矩阵即可；X 已归一化也能跑 |
| 群和群之间怎么连接？ | PAGA（轨迹与分群） | 需要分组（可自动生成） |
| 从一个有依据的起点看，细胞按什么相对顺序排列？ | DPT 扩散拟时序（轨迹与分群） | 需要起始细胞 + 生物学依据 |
| 表达正在朝哪个方向变化？ | scVelo stochastic / dynamical（速度推断） | 需要 spliced/unspliced 原始计数（X 可以是已处理的） |
| 细胞最终可能去哪几个终末状态？概率多大？ | CellRank 2 命运概率（下游命运分析） | 有速度（用速度图做核，**不需要起点**）或有 DPT 拟时序 |
| 谁在调控这些变化？ | RegVelo / dynamo / MultiVelo（调控动力学） | 需要先验网络或多组学数据，**目前多数未接入** |

**它明确不能做的事**：自动判定细胞类型、自动解释通路、用同一份数据给自己做“独立验证”、
把潜在时间说成真实几小时、把箭头说成已验证的血缘谱系、把模型输出的候选基因说成因果。
没有证据的结论，程序会留空，而不是编一个。

## 2. 你手上的数据决定能做什么

| 你有的数据 | 能做什么 | 不能做什么 |
|---|---|---|
| 只有普通表达矩阵（`X`，比如 10x 的 counts） | 质控、PCA、自动分群、UMAP、PAGA、DPT（需要起点） | **不能**做 RNA velocity、CellRank、RegVelo、MultiVelo |
| 表达矩阵 + `layers["spliced"]` / `layers["unspliced"]` 原始计数 | 上面全部 + scVelo stochastic / dynamical、CellRank 命运概率 | 需要先核查剪接层的来源；程序不会把普通 counts 猜成剪接层 |
| 表达矩阵 + 匹配的 ATAC（含峰到基因映射） | 将来可做 MultiVelo | 目前未接入 |
| 表达矩阵 + 有来源说明的先验调控网络（TF×target 0/1） | 将来可做 RegVelo（CPU 版不输出调控边） | 目前本机未安装其独立环境、未训练 |

> 普通表达矩阵**不能**凭空变成 spliced/unspliced。这不是配置问题，是数据本身没有剪接信息。

## 3. 中间主要经过哪些计算步骤

```
读取文件 → 格式体检 → 科学准入 → 你确认参数 → 本机排队 → 真实调用模型 → 统一结果 → 图形/指标 → 两份报告
```

1. **读取文件**：只接收 `.h5ad`（教学示例是内置 `.npz`）。先看维度再读入，避免一上来就把内存撑爆。
2. **格式体检**：检查行列是否对齐、ID 是否重复、数值是否有限且非负、矩阵是否整数外观、
   有没有剪接层、obs 里哪些列能当分组/供体、基因 ID 是 Ensembl 还是符号、线粒体基因命中多少。
3. **科学准入**：每个方法同时检查“科学前提”和“本机依赖”。**缺什么会写清楚**，条件不满足的方法不能被强行启动。
4. **你确认参数**：程序给出建议流程和推荐参数，但**不会替你勾选**，也不会自动挑“最好的方法”。
5. **本机排队**：任务写进本地 SQLite 队列，每个方法一个独立子进程，记录配置、环境、随机种子、耗时和日志。
6. **真实调用模型**：调用 scanpy / scVelo / CellRank 的实际函数，调用序列写进 `calls.json`。
7. **统一结果**：不管哪个方法，都输出同一套结构（二维坐标、时间/排序、指标、候选基因、解释边界）。
8. **图形与指标**：静态 SVG + 可交互 Plotly，指标在结果页可读。
9. **两份中文报告**：A 生物学分析报告、B 技术与复现报告。

## 4. 能输出什么

### 4.1 图形

| 图 | 什么时候出现 | 怎么读 |
|---|---|---|
| 质量散点图（总表达 × 检测基因数，颜色=线粒体比例） | 总是 | 找离群点；不要机械套阈值 |
| 降维图（UMAP 或 PCA） | 总是 | 二维投影会失真，距离不等于生物学差异 |
| 剪接相图 | 有 spliced/unspliced 时 | 单个基因的相图不能独立证明动力学成立 |
| 速度箭头 | scVelo 方法 | 箭头方向是模型推断，不是已验证谱系 |
| 群间连接热图 | PAGA | 无向连接强度，不代表方向 |
| 命运概率条形图 | CellRank | 模型推断；终末状态需要生物学确认 |
| 探索性基因趋势 | 有时间/排序字段且有原始计数 | 同一份数据上挑的基因，不是独立验证 |

### 4.2 指标

- 质控：每细胞总表达、检测基因数、线粒体比例、剪接比例、复杂度。
- 分群：群数量、群大小、分辨率、每群相对高表达基因（描述性，无 p 值）。
- 拟时序：可达细胞数、群平均拟时序（方向线索）。
- 速度：速度长度、速度一致性、速度伪时序可达性、每基因拟合参数（dynamical）。
- 命运：终末状态数量、每个细胞对各终末状态的概率、命运驱动基因候选（相关性）。

### 4.3 文件

```
results/
  queue.sqlite                 任务队列（跨页面刷新保留）
  inputs/                      提交时的输入副本
  <任务ID>/
    input.h5ad / input.npz     本次使用的原始副本（不改动你的原文件）
    config.json                全部参数
    environment.json           本次解释器真实安装的所有包版本
    format.json                数据格式体检结果
    validation.json            科学准入检查
    eligibility.json           每个方法能不能跑、为什么
    qc.json                    质控指标
    result.json                统一结果（界面读取的就是它）
    gene_table.json            候选基因/拟合参数
    provenance.json            输入与代码哈希、命令、种子、耗时、状态
    calls.json                 真实调用序列（函数名 + 参数）
    figures/                   全部 SVG 与独立 Plotly HTML
    analysis.h5ad              模型结果对象（如产生）
    velocity.npz               基因空间速度矩阵（如产生）
    A_生物学分析报告.md
    B_技术与复现报告.md
    A_report.html / B_report.html   可直接用浏览器打印成 PDF
```

### 4.4 两份报告

- **A 生物学分析报告**：数据质量、本次实际产生的轨迹/速度/命运结果、候选基因、参数解释、证据分级、解释边界、官方来源。
- **B 技术与复现报告**：数据格式、环境与依赖版本、超参数快照、真实调用序列、耗时、随机种子、日志、失败原因、结果路径、复现命令。

## 5. 按顺序操作

1. **读操作手册**（就是本页）：先知道自己有什么数据、能问什么问题。
2. 打开 **模型介绍**：看感兴趣的方法要什么输入、实际能输出什么、当前是不是可运行。
3. 进入 **开始分析**：
   - 第一次建议选「先体验模拟示例」，不用准备文件；
   - 有真实数据时选「导入我的数据」，上传 `.h5ad`（网页上传 ≤1024 MiB；本机文件 ≤4 GB）。
4. 看**数据体检**：它会告诉你 X 是整数计数 / 已取对数 / 已缩放，有没有 spliced/unspliced，
   obs 里哪几列能当分组或供体，线粒体基因命中几个。
5. 补上研究背景（物种/组织/样本列）和两个声明（X 是否为原始计数、剪接层是否为原始计数）。
   **只是 log 表达矩阵时不要勾原始计数**；即使勾了，程序也只会做描述性质控。
6. **推荐路径：什么都不用改，直接点「开始本地分析」。**
   默认开启的「一键分析」会自动跑完：质控 → 自动分群 → PAGA →（有剪接层）速度 →（有速度/起点）命运，
   最后只生成**一份汇总报告 + 全套图**，不需要你逐个挑方法。
7. 想单独跑某个方法（比如只想做 DPT）：把「一键分析」开关关掉，再在方法列表里勾选。
   DPT / 拟时序核算命运需要填起始细胞 ID 和选择它的生物学依据；PAGA 可以选数据里的分组列或「自动分群」。
8. 点 **开始本地分析**。每个方法会各自排一个任务（一键分析只有 1 个任务）。
9. 到 **任务结果** 页刷新：`queued` 排队 / `running` 计算中 / `completed` 完成 / `failed` 失败。
10. 看图形、指标、候选基因，下载 A/B 报告或整个结果 ZIP。失败任务先看日志与失败原因。

> 任务一旦提交就独立于页面运行：切页面、关网页不会取消它。本版本**没有**训练取消和崩溃自动续训按钮；
> 若任务长期停在 running，请检查 `results/worker.log` 与对应任务目录的 `run.log`，不要重复启动同一训练。

### 这台电脑上的大致耗时（240 细胞 × 120 基因模拟数据，全部含解释器启动）

| 方法 | 实测耗时 |
|---|---|
| 质控 / 演示 | 约 2 秒 |
| 自动分群、DPT、PAGA | 约 18–20 秒 |
| scVelo stochastic / dynamical | 约 19–24 秒 |
| CellRank 命运概率 | 约 22 秒 |

真实数据会明显更久，主要取决于细胞数、基因数与邻域规模。dynamical 和 CellRank 比质控慢一个量级以上是正常的。

## 6. 是否需要联网

| 使用场景 | 是否需要外部网络 |
|---|---|
| 首次安装、更新软件依赖（`install.py`） | **需要** |
| 安装完成后，用本地文件或内置示例计算 | 不需要 |
| 查看本地结果、画图、生成与导出报告 | 不需要 |
| 点击「官方文档（需联网）」按钮、另外下载公开数据 | **需要** |

界面地址 `127.0.0.1:8501` 指向**这台电脑**，页面由本机程序提供。
正常分析与报告整理都在本机执行：**没有云端大模型、没有 API 密钥、不会上传你的数据**。
本版本**没有**联网 AI 解读功能；如果以后增加，会作为单独开关，并明确列出会上传哪些字段。

## 6. 公开数据下载（需联网，可选）

如果手上暂时没有数据，可以直接在界面里下公开数据集：

1. 「开始分析」→「开始方式」选 **下载公开数据（需联网）**；
2. 数据来源：
   - **GEO（NCBI）**：填 GSE 编号（例如 `GSE84133`）。可以先点「查一下这个 GSE 有哪些可下载文件」确认它提供的是
     mtx / h5 / h5ad / CSV，而不是只有 SRA 原始数据或 `.rds`；
   - **CELLxGENE**：输关键词搜索，选一个数据集；或直接填数据集 UUID；
   - **任意 .h5ad 直链**：粘贴 URL。
3. 点「下载并转换（需联网）」。转换会自动补齐标准 obs 字段，并保存在 `data/public/`。
4. 下载完成后会**自动进入数据体检 → 一键分析**，不需要你手工转换格式。

注意事项：

- 下载需要外部网络；转换和后续分析都在本机完成，**数据不会被上传**。
- 一个 GSE 里混有多个物种时，程序只保留细胞数最多的物种，其余样本记在
  `uns["cellflow_public"]["dropped_species"]`，不会把人和鼠的矩阵硬合在一起。
- 只提供 SRA 原始数据或 `.rds`（Seurat）的数据集无法自动转换，程序会明确说明。
- 公开数据的**版权与引用要求属于原数据库**，发表前请核对并引用原文献。

## 7. 结果保存在哪里

- 全部保存在工作台目录下的 **`results/`** 文件夹，每个任务一个子文件夹（目录结构见第 4.3 节）。
- 输入文件会**复制**一份到任务目录，原始文件不会被修改。
- 结果页可以下载：A/B 报告（`.md`）、可打印 HTML、以及包含报告+图形+复现记录的 ZIP（不夹带原始矩阵和模型权重）。
- 报告与日志可能包含基因/细胞标识和本地绝对路径，**分享前请检查**。
- 清理：删除 `results/<任务ID>` 即可。`results/queue.sqlite` 是任务队列，建议保留。

## 7. 切换主流模型与计算设备

在「开始分析」页，一键分析下面有两个下拉：

1. **主流 RNA velocity 模型**：`deterministic`（稳态，最快）/ `stochastic`（默认）/
   `dynamical`（完整动力学，最慢）/ `veloVI`（变分，给不确定性）。
   全部是上游官方实现（scVelo 的 mode、scvi-tools 的 VELOVI），本程序只做统一调用与结果转换。
   选到尚未安装的模型时，程序会**明确说明并降级**，不会偷偷换成别的算法。
2. **计算设备**：自动 / CPU / GPU（CUDA）。
   - 本机没有 NVIDIA 显卡时选「自动」= CPU；
   - 以后连课题组服务器、装好 CUDA 版 PyTorch，选「自动」或「GPU」就会用显卡；
   - 选 GPU 而环境不满足时，会写明原因并回退 CPU。

> 说明：scVelo 的三种模式是 CPU 实现，选 GPU 不会更快；真正能吃到 GPU 的是 veloVI / RegVelo 这类神经网络模型。

### 隔离环境

不同模型的依赖可能互相冲突（例如 veloVI 需要 `numpy<2`），所以按模型分环境：

```
python install.py                    # 主环境（必需）
python install.py --include-cellrank # 可选：命运概率
python install.py --include-velovi   # 可选：veloVI（scvi-tools + CPU PyTorch，约 500 MB）
```

任务队列会**自动用对应环境的解释器**运行该任务，你在界面里不需要手动切环境。

## 8. 文件与规模限制（本原型）

- 网页上传 ≤ **1024 MiB**，本机文件 ≤ **4 GB**，矩阵合计内存约 **3 GB**（按内存判断，不死卡元素数）。
  参考：8k 细胞 × 20k 基因的稀疏矩阵约 200 MB，可以正常分析。
- 至少 **20 个细胞、10 个基因**（本原型的保守保护，不是各方法的理论阈值）。
- 不接收 FASTQ / BAM / RDS / 普通 CSV；不做 10x/Seurat 自动转换。
- 细胞数很大时（>2 万）建议先用随机子集跑通参数；>5 万时本原型基本不适合直接全量。
- CellRank 使用 GPCCA，需要把细胞×细胞矩阵稠密化，本程序在 **超过 6000 细胞**时会拒绝运行并说明原因。

## 9. 术语小词典

| 术语 | 通俗解释 |
|---|---|
| AnnData / h5ad | 单细胞数据的标准文件格式：一张“细胞 × 基因”表 + 各种附注 |
| spliced / unspliced | 已剪接 / 未剪接的 RNA 计数；velocity 方法靠两者的关系推方向 |
| 拟时序 pseudotime | 按相似度排出的**相对顺序**，不是真实小时数 |
| 速度 velocity | 每个基因在每个细胞里的“变化方向”，组合成细胞状态转移方向 |
| 稳态假设 | velocity 的常见前提：转录速率的变化比剪接/降解慢 |
| 终末状态 | 模型认为细胞“走到头”的状态；需要生物学确认 |
| 命运概率 | 模型推断的“细胞去往各终末状态的概率”，不是事实 |
| 高变基因 HVG | 细胞之间变化最大的基因，用于降维与邻域 |
| 泄漏 leakage | 用最终要评价的信息去构建特征/先验/调参，导致结果偏乐观 |

## 10. 这台电脑适合怎么用

- 硬件：Intel i5-1240P（12 核 / 16 线程）、16 GB 内存、Intel Iris Xe 核显、**没有 NVIDIA 独立显卡**。
- 默认 **纯 CPU**，不安装 CUDA、不需要 NVIDIA 驱动。没有独显不影响做质控、分群、轨迹和 scVelo 速度。
- 计算子进程默认限制为单线程（`OMP_NUM_THREADS=1` 等），避免 16 GB 机器被同时占满；代价是慢一点、但更稳。
- 建议路径：先模拟示例熟悉界面 → 用小规模真实数据检查质量与参数 → 再考虑全量。
- 需要更快的神经网络方法（veloVI / DeepVelo / UniTVelo / VeloAE）时，再评估是否值得投入 GPU 或云资源；
  这些方法目前在本程序中**只是注册与说明，尚未接入**。

## 11. 解释边界（请务必读一遍）

- 潜在时间 / 拟时序 **不等于**真实时间；箭头 **不等于**已验证谱系；候选调控关系 **不等于**因果证据。
- 不同模型的损失、似然、潜在时间尺度**不能直接排名**，本程序不给出“最佳模型”。
- 比较两个模型时，需要检查：细胞与基因集合、预处理、评价空间、随机种子、计算预算是否一致。
- 正式评测要按供体/样本拆分，防止特征选择、先验网络、调参与评价标签之间泄漏。
- 细胞不是独立生物学重复；本程序不做组间显著性检验。
- 模拟数据的结果**永远**标记为模拟，不能当作生物学发现。
- 缺少证据的细胞类型、通路和生物学结论，保持“未知”。
