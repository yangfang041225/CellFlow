# 数据流水线（导入 → 匹配 → 运行 → 报告）

## 1. 数据来源

| 来源 | 入口 | 实现 | 实测状态 |
|---|---|---|---|
| 本地上传 | 数据页「上传文件」 | `api.upload` → 保存 `results/inputs/<sha16>.<ext>` | 通过（含中文路径、无效格式拒绝） |
| 本机路径 | 数据页「本机路径」 | 只接受项目数据目录内的已登记文件 | 通过 |
| 公开下载 | 数据页「公开数据」 | 后台任务 `downloads.submit` → `publicdata.fetch`（GEO / CELLxGENE / URL）；支持进度与取消 | GEO 实测通过；CELLxGENE API 可达；大文件未实测 |
| 内置示例 | **仅测试/API**，正式界面不显示 | `examples/synthetic.npz` | 通过 |

> 任务快照（`results/inputs/<jobid>.<ext>`）是执行副本，不会作为数据集重复列出。

## 2. 格式支持与方向判断

- `.h5ad`、`.loom`、10x `.h5`、10x 三件套目录、CSV/TSV、zip/tar.gz。
- 所有导入入口先做内存预检（超过可用内存 90% 直接拒绝，并说明预计/可用）。
- CSV/TSV 导入会在说明里记录文件大小与估算峰值；元数据列先复制再丢弃，降低转置/类型转换峰值。
- 超过 32 MB 的表格自动走分块读取（每块 4000 行 → float32 稀疏 → 纵向/横向拼接）；可用 `CELLFLOW_STREAM_CSV=1` 强制分块，便于验证。
- 10x 三件套读前校验：matrix 非空、features 存在、矩阵维度与 features 一致、barcodes 数与细胞轴一致、计数非负；缺 barcodes 用 `cell_1…` 占位并写入导入说明；非整数计数给出警告。
- 方向：按基因名/细胞条码特征判断；必要时自动转置，并在报告里记录转置事实。
- 只读原文件：导入时复制快照，不修改源文件。

## 3. 内存预检

读取前先估算峰值内存（h5ad/h5/loom 读 h5py 头部的 shape 与稀疏 nnz；文本×4；压缩×5），超过当前可用物理内存 90% 时：API 返回 413、任务失败并给出“预计/可用”数字，避免 16 GB 机器被拖死。估算不是精确值，只用于提前拒绝明显装不下的文件。
运行中还会在「读取完成 / 计算前 / 绘图前」检查可用内存：低于 1 GB（读取后/绘图前为 0.5 GB）直接失败并写日志，避免系统级 OOM。

## 4. 数据体检（inspect）

| 检查 | 实现 | 用途 |
|---|---|---|
| 维度、dtype、稀疏性、非零比例 | `data.inspect` | 展示与准入 |
| X 状态（counts/log/scaled） | `data.x_kind` | 决定是否归一化；未确认原始计数时拒绝做数值改写 |
| spliced/unspliced 层 | 层存在 + 与 X 形状一致 | 速度类方法前提 |
| 线粒体基因 | 前缀匹配 | 质量提示（不自动删细胞） |
| obs 列、分组候选 | 唯一值/缺失率 | 分组与起点选择 |

## 4. 模型匹配（eligibility）

每个方法在 `registry.py` 声明：`needs`（数据前提）、`packages`（依赖）、`runtime_env`（环境）。
准入结果分三类原因：

1. **科学前提缺失**：如缺 spliced/unspliced、缺起点；
2. **依赖缺失**：主环境或隔离环境未安装；
3. **环境/资源限制**：CUDA、内存、细胞数上限。

界面显示“可运行 / 缺什么”，按钮与提交使用同一份校验结果；**不会自动替换模型**。

## 5. 预处理边界

- 允许派生：PCA、邻居图、UMAP、moments、速度图。
- 禁止伪造：不能生成不存在的 unspliced 计数、不能把普通表达当剪接数据、不能把随机 GRN 当先验。
- 未确认“X 是原始计数”时，`_prep_expression` 直接停止并说明原因（审查 F02）。

## 6. 执行与产物

```
results/<task_id>/
├─ input.<ext>            输入快照（只读副本）
├─ config.json            实际配置
├─ environment.json       解释器已安装包
├─ source/                运行时源码副本
├─ validation.json        数据校验
├─ format.json            格式体检
├─ eligibility.json       方法准入
├─ qc.json                质控指标
├─ result.json            统一结果结构
├─ velocity.npz           速度矩阵（速度类方法）
├─ figures/*.svg          图形（qc/embedding/phase/trends/paga/fate）
├─ A_生物学分析报告.md     生物学报告
├─ B_技术与复现报告.md     技术报告
├─ A_report.html / B_report.html
├─ quality.json           结果质量校验（维度/NaN/图/时间长度）
├─ provenance.json        环境、哈希、耗时、状态、失败阶段；运行中按阶段即时更新
└─ run.log                全过程日志
```

## 7. 结果质量校验（quality.json）

不评价生物学对错，只检查结果是否自洽。当前 14 项：result.json 可解析；速度矩阵维度与细胞/基因一致、无 NaN/Inf；分群大小之和等于细胞数；嵌入维度与细胞数一致且有限；命运概率行数/范围/行和；PAGA 对称性与取值范围；指标有限；速度置信度在 0–1；时间长度；候选基因都在基因表；至少一张图。结构性失败 → `ok=False`；软问题（范围/归一/基因缺失）只写 `warnings`，不否定计算完成。

## 8. 报告

- **A 生物学分析报告**：数据与输入来源、QC、分群、动力学结果、候选基因、解释边界、证据来源。
- **B 技术与复现报告**：解释器/依赖/线程、数据哈希、实际参数、调用记录（`calls.json`）、耗时、失败阶段、复现命令。
- 报告图片链接由 API 改写为 `/api/runs/{id}/figure/...`，避免相对路径 404。
- PDF：Qt 逐页绘制，页眉为「CellFlow · 任务 ID · 日期」，右上角「第 N / M 页」，页脚为来源说明；
  `_ensure_report_pdf` 用 `.pdf_version` 标记缓存版本，升级格式后会自动重生成旧 PDF。
- 失败任务：仍生成“失败说明”报告，不生成可解释的生物学结论。

## 9. 删除与保留

- 删除任务记录只删队列行；结果目录默认保留（可在文件管理器手动清理）。
- 数据集登记删除不影响已复制到任务目录的输入快照。
