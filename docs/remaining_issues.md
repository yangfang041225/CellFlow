## P3 工程事项

- 无 Git 仓库：改动只能靠 `.tmp`/备份目录与测试保证；建议初始化 Git。
- PySide6 的 LGPL 分发义务、igraph 的 GPL 传染性需要发布前做完整审计（见 `THIRD_PARTY_NOTICES`）。
- npm 构建有 >500 kB chunk 警告；可后续做代码分割。
- 干净环境重装未实测（当前机器环境是既有安装）。
- macOS/Linux 未验证；启动器只支持 Windows。
