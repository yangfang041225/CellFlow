# 第三方代码与许可

CellFlow 自己写的部分（界面、准入规则、报告生成、结果 schema、调度）以项目内约定使用。
下面列出**直接参考或改写**的第三方代码，按各自的许可证使用，并在此声明来源。

## 1. h5adify（MIT License）

- 来源：PyPI `h5adify` 0.1.1，Copyright (c) 2025 h5adify contributors
- 许可证：MIT
- 本项目的复用了它的**设计思路**，代码是重写的（不是原样拷贝）：
  - 「搜索 → 按 ID 下载 → 转成标准 h5ad → 补齐 obs 元数据」的整体流程；
  - obs 标准字段清单（source / dataset_id / sample_id / species / technology / modality /
    tissue / condition / disease），见 `cellflow/publicdata.py` 的 `OBS_REQUIRED`；
  - CELLxGENE 走公开 API 搜索、按数据集 UUID 直链下载 `.h5ad` 的方式；
  - 从 tar/zip 里找 10x / h5ad / h5 矩阵的兜底顺序。
- **没有沿用**的部分：它用 `GEOparse` + `beautifulsoup4` + `lxml` 抓 GEO；
  本项目改成直接读 NCBI 的 HTTPS 目录与 SOFT 元数据，**少三个依赖**，并额外支持
  「GEO 上常见的 CSV 计数表」（例如 GSE84133 的 Baron 胰腺数据）。
- 与原项目不同的行为：
  - 下载支持**断点续传 + 自动重试**（NCBI 经常中途断开）；
  - 自动识别 GEO 里混着的多个物种，**只保留细胞数最多的物种**，其余记在
    `uns['cellflow_public']['dropped_species']`，避免把人和鼠的矩阵硬合在一起；
  - 转换后的 h5ad 直接进入 CellFlow 的体检 → 一键分析流程。

## 2. 其它依赖

CellFlow 不打包任何第三方库的源码，全部通过 pip 安装，遵守各自许可证：

| 包 | 用途 | 许可证 |
|---|---|---|
| anndata / scanpy | AnnData 读写、预处理、分群、DPT、PAGA | BSD-3-Clause |
| scvelo | RNA velocity | BSD-3-Clause |
| cellrank | 命运概率（可选） | BSD-3-Clause |
| streamlit / plotly | 本地界面与交互图 | Apache-2.0 / MIT |
| numpy / scipy / pandas / h5py / igraph | 数值与 IO | BSD / Apache |
| requests / urllib3 | 公开数据下载 | Apache-2.0 / MIT |

公开数据的**版权与使用条款属于各自数据库**（GEO / CELLxGENE / 数据集作者）。
下载数据前请自行确认该数据集的使用许可与引用要求；CellFlow 只负责传输与格式转换，不改变原始数据的版权状态。
